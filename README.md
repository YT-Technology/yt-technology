# YT Technology — Cinematic Edition

Static website for GitHub Pages. Built with HTML, CSS and vanilla JavaScript; no build step or paid service required.

## Publish
1. Extract the ZIP.
2. Upload the contents of this folder to the root of the GitHub repository used by GitHub Pages.
3. In repository Settings → Pages, select the intended branch and `/ (root)` if not already configured.

## Included
- Arabic/English language toggle
- Responsive layout and reduced-motion support
- Portfolio links for Miftah and Collection Car
- Contact links and WhatsApp project inquiry form
- Transparent PNG logo and SVG favicon/social preview
