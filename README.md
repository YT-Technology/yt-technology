# YT Technology

Static site (HTML/CSS/JS). Structure: `index.html`, `css/style.css`, `js/main.js`, `assets/logo.svg`.

## Deploy on GitHub Pages
1. Upload all files to the root of a repository.
2. Settings > Pages > Deploy from a branch > `main` / `/ (root)`.
3. Your site goes live at `https://<user>.github.io/<repo>/`.
